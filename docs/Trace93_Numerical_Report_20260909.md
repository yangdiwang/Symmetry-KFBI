## 1. 配置与证据范围

本轮独立入口为 `kfbi_trace93_study_3d`，中心策略 `trace`，事件模式 `python93`。
这对应 event-owner 验证的 trace-first 修正，而不是旧 torus 的邻 patch 近邻策略。
物理几何采用精确双三次 NURBS；密度在 Python analysis chart 上使用独立三次 B 样条。
三种几何为 14 片实心圆柱、14 片 L 柱、22 片 U 柱，尺寸以新算例工厂为准。
圆柱是半径 `R=0.54` 的封闭实心圆柱，不是此前空心圆柱；L/U 也与旧本地参数不同。
因此旧 L/U 数值不能直接作为本轮同一几何的前后对照。
刚体变换为 `rotate`，即 `(17,-11,13)` 度、`Rz Ry Rx` 顺序，无平移。
N 用 Q27-cover3，D 用 Q64-cover4，Spread P3、Restrict P2，3+3 法向采样。
密度 cell 使用 4×4 Gauss 外迹点；N 的 edge-star 权重 0.1，vertex-star 默认权重 0。

## 4. Dirichlet 的固定约束缺陷

初版单测要求所有布局 `||Ccp-d||∞<2e-8`，在 L32 D 失败；原因是测试假设与参考源不一致。
查证包内 rotate 记录后，以下缺陷本来就存在：

| 布局 | 包内归一化约束残差 |
|---|---:|
| L32 D | 1.388067457558373e-6 |
| L64 D | 4.967766834840237e-7 |
| U32 D | 4.8586834837660575e-6 |
| U64 D | 1.7897361606067363e-6 |

原因是各特征边上的非多项式已知边界数据分别插值为三次边样条，其端部 jet 不必与全部 smooth C1 约束精确相容。
Python 使用最小范数约束最小二乘特解，而不是声称原始 `Cc=d` 精确可行。
本地保留这一流程：`δ=Ccp-d` 固定，迭代 `c=cp+Zy` 保持 `Cc=d+δ`。
这不是 GMRES 中拟合未知密度，但也不能称为原始已知边数据的全部等式都精确满足。
本轮未修改该算法；单测改为逐项核对档案缺陷，并检查 `Cᵀδ≈0`、`Zᵀcp≈0`、`CZ≈0` 以及迭代坐标保持 δ。
修订后 12 布局测试通过；L32 D 的 PDE 结果已在上节单独给出，其他 D 配置不能据此类推。
