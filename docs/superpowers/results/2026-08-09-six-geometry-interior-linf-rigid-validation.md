# 六类三维曲面的内部最大误差与刚体稳定性

本报告只统计内部笛卡尔节点上的最大误差

\[
E_\infty=\max_{x_i\in\Omega^-\cap G_h}|u_h(x_i)-u(x_i)|,
\]

以及达到相对容差 `2e-10` 时的 GMRES 迭代数。表中每个条目均写成
`E_inf (iterations)`；不混入内部 L2、外部体误差或外迹误差。

## 离散与姿态

- 球、椭球和花形面采用光滑 cap-atlas 密度空间；外迹积分在每个密度
  单元使用 `3 x 3` Gauss 点。
- 圆柱、L 棱柱和圆环采用原生 NURBS/C0 密度空间；Neumann restrict
  使用全局三次外侧分支、panel-center 采样以及 owning patch 上的
  `c0_one_sided` value jet。
- 两类计算都使用约化密度系数、trace-mass 坐标、
  projected-elimination compatibility border、自动密度分辨率和最多 80 次
  GMRES。
- 当前 `cylinder` 模型是精确有理二次 NURBS 的封闭空心圆柱。

八个姿态为：基准；三个单轴平移 `(0.137,0,0)`、`(0,-0.083,0)`、
`(0,0,0.061)`；两个三轴平移 `(0.137,-0.083,0.061)`、
`(-0.109,0.151,-0.047)`；绕中心 `(0.07,-0.07,0.02)`、轴
`(1,2,3)/sqrt(14)` 旋转 17 度；以及该旋转再叠加第一组三轴平移。
制造解随刚体变换作逆映射，因此连续问题在变换前后等价。

## 稳定性结论

八姿态 N=32 的 GMRES 迭代范围分别为：圆柱 `22--24`、L 棱柱
`23--31`、圆环 `17--18`、球 `9--13`、椭球 `10--13`、花形面
`12--16`。所有已报告计算的 coefficient-space GMRES 均为
`converged=1`；原始 CSV 中的 `physical_converged` 是物理外迹与相容性
接受诊断（还联合检查外迹、border closure、相容性与加权均值），不是这里
报告的 coefficient-space GMRES 收敛标志。

六个几何的基准与最强组合姿态共 12 条 `N=32 -> 64 -> 128` 最大误差
序列均严格下降。72 个唯一算例中的最大 GMRES 迭代数是 L 棱柱强组合
姿态 `N=128` 的 36 次，低于 80 次上限。

刚体变换改变曲面与笛卡尔网格的相对对齐，因此离散最大误差不应逐位
相同。稳定性的判据是误差保持同量级、加密后下降、迭代数不随姿态或
网格密度失控，而不是要求每个姿态给出相同误差。
