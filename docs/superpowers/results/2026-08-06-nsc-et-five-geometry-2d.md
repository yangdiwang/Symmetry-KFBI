# NSC-ET-KFBI：五类二维精确 NURBS 几何结果

日期：2026-08-06

## 方案

正式方案名为 **NSC-ET-KFBI**（NURBS–Spline-Coefficient
Exterior-Trace KFBI）。其未知量是分片 B 样条的约化系数，而不是边界点值：

- \(\phi=[u]\) 使用 P3，\(\psi=[u_n]\) 使用 P2；
- knot break 先按目标物理间距 \(H=1.5h\) 在弧长上布置，再反求精确
  NURBS 参数；
- G2 连接采用 \(\phi\)-C2/\(\psi\)-C1，G1 采用
  \(\phi\)-C1/\(\psi\)-C0，G0 采用
  \(\phi\)-C0/\(\psi\)-不连续；
- crossing 处直接从系数计算弧长导数，并结合精确 NURBS 的切向、法向和
  曲率构造完整空间 P2 Cauchy 多项式；
- spread 和 USN-P2-DOF-EXT restrict 消费同一个不可变系数状态，不在
  GMRES matvec 中重新拟合密度；
- Dirichlet 固定 \(\phi=g_D\)、迭代 \(\psi\)，令外法向迹为零；Neumann
  固定 \(\psi=g_N\)、迭代 \(\phi\)，令外值迹为零，并施加物理均值规范；
- 光滑闭曲线的外迹判断点从等弧长半面板点中准均匀抽取；多分支几何采用
  分支感知的满秩选择。系数到这些点的密度值映射 \(D\) 仅作为右基预条件
  \(D^{-1}\)，最终未知量仍是 B 样条系数，GMRES 残差仍是真实逐点外迹。

P2 compatibility panel 仅提供网格拓扑和采样候选；交点、微分几何和密度
求值均来自权威 NURBS provider，不使用 P2 几何近似。

## 实验设置

- 方程：二维调和 Laplace BVP；计算盒 \([-1.5,1.5]^2\)。
- 制造解：
  \[
  u=x^3-3xy^2+0.35(x^2-y^2)+0.20x-0.15y+0.10.
  \]
- Neumann 解按边界均值固定常数规范。
- 网格：\(N=16,32,64,128\)，\(h=3/N\)。
- GMRES：相对容差 \(10^{-9}\)，restart 80，最多 160 次。
- restrict：USN-P2-DOF-EXT，完整二维总次数 P2 空间插值和统一法向 P2。
- 几何：精确有理二次圆、仿射圆得到的精确椭圆、周期三次 NURBS 花形、
  分段三次 NURBS 心形、六条一次 NURBS 组成的 L 形。

## 稳定性与 fallback

- 40/40 个最终求解均达到 GMRES 容差；最大外迹 \(L_\infty\) 为
  `4.7028443e-9`。
- 实际平均 \(H/h\) 位于 `[1.2874, 1.4982]`；分支长度取整保证不超过
  目标 1.5。
- 所有最终行的 unresolved-gap fallback 和 endpoint fallback 都为 0。
- circle、ellipse、flower 和 L-shape 的 stencil relocation/rejection 为
  0；heart 每层为 1 次 relocation、10 次候选 rejection，但没有进入
  crossing fallback。
- 未做系数基预条件时，L-shape/Neumann 在 N=64 达到 160 次上限仍未
  收敛，bulk 误差为 4.425；加入 \(D^{-1}\) 后为 21 次、
  `9.8063e-3`。这说明预条件消除的是系数坐标的基尺度问题。
- 单纯用 QR 选取光滑花形外迹行虽满秩，但空间聚簇导致 Neumann N=64/128
  bulk 误差停在 `5.8430e-2/5.0680e-2`；准均匀外迹选择后变为
  `4.1269e-3/4.5810e-4`，GMRES 为 15/16。
