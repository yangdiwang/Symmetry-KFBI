# USN-P2 restrict：花形 BVP 数值比较

## 方案定义

新方案正式命名为 **USN-P2（Unified Spatial-Normal P2 Restriction，统一空间—法向 P2 限制）**。
它可由 BVP 选项 `LaplaceBvpRestrictMethod2D::UnifiedSpatialNormalP2CrossingOwner`
直接选择，不需要调用方手工组合内部 restrict 参数。

对每个界面自由度和每个物理侧，USN-P2 执行以下步骤：

1. 在离界面最近的同侧网格节点上构造“中心 + 四个轴向邻点 + 一个对角点”的完整二维 P2 模板，基为
   \(1,x,y,x^2/2,xy,y^2/2\)。
2. 若模板包含异侧节点，只接受恰好一个横截交点，并在真实交点处用 BVP 选择的界面样条信息构造完整 Cauchy jump 多项式进行修正。
3. 最近锚点的四个对角候选都不合法时，只把同一格式的 P2 模板移动到下一个同侧锚点；不允许退回 expansion-center 多项式、gap owner 或 endpoint owner。若所有局部模板均不合法，则显式报错。
4. 一侧只选择一次空间模板；\(0.2h,0.6h,1.0h\) 三个法向采样点共享相同节点及 crossing owner，只改变 P2 评价权重。
5. 在界面自由度处根据 `phi-P3`（Dirichlet）或 `psi-P2`（Neumann）样条信息和 PDE 闭合构造完整二阶 jump 多项式，将两侧物理样本转换到同一虚拟分支。
6. 对六个虚拟样本统一拟合一个法向二次多项式，并读取界面值和法向导数。

新增的 **USN-P2-DOF-EXT** 由
`LaplaceBvpRestrictMethod2D::UnifiedSpatialNormalP2DofCauchyExterior`
选择。它保留相同的共享完整空间 P2 模板，但有三点不同：

1. 所有异侧空间节点都使用当前界面自由度处的同一个局部 Cauchy 多项式修正，不再使用各网格边 crossing 处的局部多项式。
2. 界内法向样本在计算完成后立即减去该自由度 Cauchy 多项式，直接转换为外侧虚拟解；界外法向样本保持不变。
3. 只对这一个外侧虚拟分支拟合法向 P2；average/interior/exterior 输出仅在界面点恢复 \(1/2\)、1、0 倍 jump，不再构造两套法向多项式并平均。

比较对象为旧 `six_point`、旧 `joint_cubic`、`usn_p2` 和
`usn_p2_dof_ext`。

## 实验设置

- 计算盒：\([-1.25,1.25]^2\)，\(h=2.5/N\)。
- 网格层：\(N=32,64,128,256\)。
- 几何：3、5、7 瓣旋转并平移的花形曲线。
- BVP：Interior Dirichlet 与 Interior Neumann，均采用 exterior-trace Cauchy 迭代。
- 精确解：\(u=e^x\cos y+0.12(x^2+y^2)\)，因此 \(-\Delta u=-0.48\)。
- crossing jet：ALS-CJ；Dirichlet 使用周期 B-spline `phi-P3`，Neumann 使用周期 B-spline `psi-P2`。
- GMRES：最多 100 次，容差 \(2\times10^{-10}\)，restart 60。
- 总计：3 个几何 × 2 个 BVP × 4 个 restrict × 4 个网格层 = 96 个求解。

主要结论：

- 96/96 个求解全部达到 GMRES 容差。
- USN-P2 在六组几何/BVP 上均保持约二阶的整体收敛，四层拟合的 \(L_\infty\) 阶为 2.09–2.42。
- USN-P2 的总 GMRES 范围为 9–15；`joint_cubic` 为 9–17；`six_point` 为 9–31。
- 稳定性优势在复杂 Neumann 情形最明显。flower7/Neumann 上，USN-P2 的迭代数由 14 降到 11，最细误差为 1.2151e-5；`six_point` 的迭代数升到 31，且最细层出现负的逐层 \(L_\infty\) 阶（-0.543）。
- USN-P2 不是所有 Dirichlet 情形下误差常数最小的方案：flower3 与 flower5 的最细层误差高于两个旧方案；它的主要收益是统一格式、严格 crossing 绑定和更稳定的迭代行为。

DOF-EXT 与原 USN-P2 的最细层误差差异为 -5.0% 至 +1.5%，四层
\(L_\infty\) 拟合阶差不超过 0.06。Dirichlet 的 GMRES 基本不变；
Neumann 通常多 1 次，flower3 最多多 2 次。因此去掉法向双分支修正没有损失
二阶精度，但这组算例中也没有显示出迭代数优势。

## 模板与 fallback 诊断

对每个几何只列一次，因为模板诊断与 Dirichlet/Neumann 数据值无关。

| 几何 | 网格层 | 模板平移 | 候选拒绝 | gap / endpoint fallback | max ||w||1 | max anchor distance / h |
|---|---|---:|---:|---:|---:|---:|
| flower3 | 32–256 | 0 | 0 | 0 / 0 | 1.7345 | 0.7068 |
| flower5 | 32–256 | 0 | 0 | 0 / 0 | 1.7288 | 0.7066 |
| flower7 | 32–256 | 0 | 0 | 0 / 0 | 1.7354 | 0.6958 |

因此两种 USN 路径在本组光滑花形实验中都没有触发同格式平移；所有模板都由最近同侧锚点直接认证。实现中保留了同格式平移路径，但不存在退回旧 expansion-center、gap 或 endpoint 修正的路径。
