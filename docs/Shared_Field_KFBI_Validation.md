## raw 方案与完整对照矩阵

N32 的两个 shared/raw D 均达到 800 步上限，真实残差约 5.29e-4 / 5.67e-4。
两个 shared/raw N 投影残差虽收敛，内部 Linf 误差却为 0.0645263 / 0.0191159。
这些行明确标为研究失败，不用退出码或小方程残差替代物理验收。
这与 Python 的失败机制一致；新共享后端默认候选是 input_jump_half。

其余 32 组均通过：12 组本地 baseline、12 组 shared/input_jump_half，以及
N64/128 的 8 组 shared/raw。全部 24 组共享方案与包内参考的 GMRES 步数一致，
内解 Linf 误差的最大相对差为 8.344e-8。这个比较包含不收敛 raw 迭代的最终状态，
不把复现失败理解为该方法通过数值验收。
完整矩阵的进程峰值工作集最大为 1.5726 GiB。

完整汇总保留独立的配置完整性、候选验收、全部所选行验收和回放标志。
