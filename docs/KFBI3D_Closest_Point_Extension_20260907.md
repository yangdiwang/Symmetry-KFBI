# NURBS 最近点跳跃延拓分支

本次实现由用户批准，用于空心圆柱 Q27 支撑线近切向求交导致的预处理失败。新分支以网格节点到真实 NURBS 边界的最近点为 Cauchy 展开锚点，将节点值延拓到目标侧，再使用原有 Q27/Q64 插值权重取迹。

## 代码与运行入口

- `src/geometry/nurbs_surface_closest_point_3d.hpp/.cpp`：不可变最近点索引、调用方复用工作区、保守距离及定位界。
- `src/support/trace/closest_point_trace_extension_3d.hpp/.cpp`：最近点与目标面点的局部光滑曲面归属检查，生成原生参数锚点。
- `apps/laplace/3d/neumann_exterior_zero_trace_3d.cpp`：缓存查询，构造锚点处的 Cauchy 修正，保留原有取迹层与密度系数绑定。
- `tests/geometry/nurbs_surface_closest_point_3d_test.cpp`、`tests/trace/closest_point_trace_extension_3d_test.cpp`：几何界、接缝、预算、折面拒绝及制造解测试。

选择新分支：

```powershell
$env:KFBIM_3D_SUPPORT_PATH='closest_point'
$env:KFBIM_3D_SOLVE_SELECTION='neumann_only'
$env:KFBIM_3D_PREPROCESS_ONLY='1'
& ./build-layout/apps/Release/kfbi_topology_affine_exterior_trace_3d.exe cylinder 32
```

运行完整制造解求解时，将 `KFBIM_3D_PREPROCESS_ONLY` 设为 `0`。原来的 `legacy` 和 `native_certified` 模式保留；默认仍为 `legacy`。新分支要求 Q27/Q64，输出自动进入独立的 `closest_point` 子目录。`KFBIM_3D_OUTPUT_ROOT` 可指定输出根目录。

`PREPROCESS_ONLY` 的完成范围是网格几何、取迹模板、常量探针及所需密度传递/绑定。它在求解专用的拓扑约化和 GMRES 之前停止。单独的 `*_preprocess.json` 记录实际范围，不能将其等同于完整 PDE 求解成功。

## 数值方法

设支撑网格节点为 A、目标面点为 P，最近点为 Q。对已验证可用的局部光滑锚点，在 Q 处构造原有阶数的 Cauchy 跳跃多项式，并在 A 处求值。对 `[u]=u_inside-u_outside`，修正符号为：

```text
sign = int(desired_inside) - int(node_inside)
continued_value(A) = physical_value(A) + sign * jump_extension_at_Q(A)
```

曲率、值跳跃和法向跳跃导数继续由原有 Cauchy 代码处理。Q 的真实 patch/u/v 进入系数绑定，不替换为附近已有的网格线交点。

最近点索引复用 polar 求值提供可行候选，使用精确提取得到的齐次控制网和向外舍入的区间界进行全局搜索。距离下界结合 AABB 与控制网支持平面；严格的驻点符号检查排除不可能含最小值的区域，原始 span 边界按约束最小化保留。

位置控制网 H 与一阶导数控制网 Hu/Hv 均在原始 Bézier span 上精确提取，再按各自阶数一起执行 de Casteljau 仿射细分。这样避免深层近重合位置控制点相减导致的导数区间膨胀；没有放宽距离、定位容差或查询预算。

`Bounded` 表示全局最小距离的上下界差满足要求；`localized` 表示所有剩余可能的全局最小点已被一个足够小的空间球包围。两者都不宣称数学上的唯一性。普通可行采样点仅提供上界，不直接视为额外最近点；共点的不同 patch 归属保留。

应用中每个网格节点只查询一次，其结果在不同目标面点间共享，但每个目标点仍单独检查局部适用性。当前设置为距离界差 `1e-9*h`、定位半径 `1e-6*h`、最多 2048 个搜索区域。

## 局部适用范围与原路径处理

接纳锚点需要满足距离/定位状态、有效法向、同一实体分量和 G1 曲面、法向兼容、局部距离和近法向投影检查。C0 连接处拒绝；存在内部 C0 knot 的目标或锚点 patch 也保守地整片拒绝。当前空心圆柱的闭合连接拓扑完整；推广到未声明完整边界连接的模型前，需要先补齐拓扑信息。

不适用的节点继续使用原来的全事件支撑路径，统计拒绝原因并保留原有认证失败。即使节点和目标侧的内外标签相同，也必须先确认局部锚点适用；这样不会跳过跨薄壁路径上的双穿越修正。Cartesian 网格边求交及区域标记算法没有改动。

## 验证记录

原始失败样例是 `center=507, grid_node=13519`，A=`(0.5625,-0.28125,-0.375)`，P 位于 `outer_wall_q3` 的 `(u,v)=(0.65,0.25)`。

针对性测试已验证该点的最近点与圆柱解析几何一致，以及真实曲率 Cauchy 延拓和 Q27 插值对二次调和函数的双侧值/法向导数再现。完整运行及耗时以 `output/nurbs_closest_point_20260907/REPORT.md` 中的最终验证记录为准。

最终导数网版本的 N32 预处理已完成全部 1160 个面点及密度绑定：阶段耗时 25.1858 秒，其中最近点查询 16.8139 秒，旧路径求交 6.0259 秒。2931 次节点查询产生 59709 次缓存命中，25907 次跨侧修正，25907 次已验证的同侧跳过；10826 次回退中，9828 次为曲面或法向不相容、990 次为特征接触、8 次为定位未决。回退仍执行原有检查，没有将未决路径当作成功。常量双侧值误差均小于 7.4e-15。

N64 同样完成全部 4200 个面点及密度绑定，12072 个查询没有定位未决，最多使用 555 个搜索区域。20626 次回退由 18542 次曲面或法向不相容和 2084 次特征接触组成，均通过原路径检查。两个网格的标签不一致、间隙穿越和不安全变号边计数均为 0。

| 网格 | 预处理阶段 / 秒 | 最近点查询 / 秒 | 回退求交 / 秒 | 查询数 | 缓存命中数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| N32 | 25.1858 | 16.8139 | 6.0259 | 2931 | 59709 |
| N64 | 77.4531 | 61.0900 | 5.7823 | 12072 | 214728 |

计时范围为前述 trace/density 预处理阶段；不含求解专用拓扑构建和 GMRES。N64 的常量双侧值误差均小于 2.0e-14。加密改变了路径长度和几何位置，回退时间不能只按总面点数线性外推。

旧流程在中途失败，因此不能用它的失败耗时计算完整预处理的加速比。同一组 227 个真实网格节点的独立查询对照中，导数网改动使总查询时间从 36.1307 秒变为 1.1107 秒，预算耗尽从 125 个降为 0 个；这仅是查询样本对照。

Release 构建通过；两个新增测试及八个相关回归测试共 10 项全部通过，覆盖 polar 求值/求交、原生端点路径、调和多项式、支撑点选择、Q27 插值及直接系数 Cauchy。几何区间界、导数网细分和应用侧修正符号也完成了独立审查。

另用外侧场 `exp(y)*cos(z)` 和跳跃场 `exp(x)*cos(z)` 做局部非多项式实验：输入解析 jump jets，执行真实最近点、锚点选择、曲率 Cauchy 和 Q27 重构链，对两个外壁点和两个内壁点分别检查两侧值及法向导数。下表为这 8 个点侧组合中的最大误差，不是全表面 Linf：

| --- | ---: | ---: |
| N64 | 1.39982e-5 | 5.67078e-4 |
| N128 | 7.92387e-7 | 9.98795e-5 |

这三个网格上的全部 27 点锚点均可用。最初的 N32 内壁样本存在曲面或法向不相容的支撑点，被保护条件拒绝；原始记录保留，局部实验转为 N64/128/256，没有放宽接纳条件或挑选新的面点。生产程序在 N32 该类位置使用回退分支，完整运行已覆盖它。局部实验不包含密度系数拟合、Poisson 和 GMRES，其观测阶受格点相位影响，不能由少量点宣称统一收敛阶。

开发过程中发现的两类问题需与最终测量区分：单纯距离细分无法有效完成空间定位；深层子控制网差分形成的导数区间又会产生定位宽度下限。最初两次 N32 开发运行分别超时或被提前停止，均不能作为成功预处理或最终性能数据。

MSVC 2017 构建还需要将原有非可复制 `ReducedTraceProjection3D` 工厂返回值改为 `unique_ptr` 所有权；构造参数和数值算法保持一致。
