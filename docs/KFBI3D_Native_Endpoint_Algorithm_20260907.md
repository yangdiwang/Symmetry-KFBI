## 1. 设计结论与边界

将当前“固定延伸路径 → 通用求交重新发现已知端点 → 固定距离匹配端点”改为：

> 原生参数定义端点 → 端点存在性见证与局部唯一性认证 → 全候选区域覆盖 → 认证驱动的根身份与顺序 → 保留现有条件端点延拓。

这不是删除失败检查，也不是向不完整根列表强行补一个端点。只有根存在性、局部唯一性、全路径完整性、事件方向及代表点精度均满足契约，才允许进入算子装配。

### 1.1 保持不变

- 保留现有 NURBS 几何、控制点、节点向量、权重和刚体变换；不以解析圆柱替代生产几何。
- Neumann 继续使用 Q27-cover3；Dirichlet 继续使用 Q64-cover4；不恢复 Q10。
- 不改变 jump 定义、Dirichlet 仿射密度空间、Neumann 密度路线、C0/C1/Vertex 自由度约束。
- 不改变 GMRES 容差、网格密度选择、空间 stencil 和现有 all-event correction 原理。
- 保留 BVH、Bézier 提取/细分、种子和数据复用框架；其中用于严格认证的几何包围必须满足本文的舍入契约。

### 1.2 分期能力

| 情况 | 第一期处理 | 后续扩展 |
|---|---|---|
| 原生 patch 内部、可以认证横截性的已知端点 | 必须支持，覆盖本次三条失败路径 | 常规维护 |
| 极小但非零横截性 | 自适应缩盒/提高精度；预算内证明后接受 | 优化成本 |
| 真正切触、重叠、曲面奇异点 | 返回明确未决/不支持原因，不伪造事件方向 | 单独的重根与接触认证 |
| 已知端点位于 seam、C0 棱边、Vertex | 第一期明确拒绝；不删除现有 owner 完整性保护 | 完整 incident-owner 与单侧区域认证 |
| 路径内部的多 owner 事件 | 保留完整 owner；只有根身份及状态变化有足够认证依据才接受 | 完善一般特征事件认证 |
| 起点恰位于边界 | 第一期拒绝并报告 `StartOnBoundary` | 双端点原生查询 |

“第一期支持本次三例”是验收目标，不是已有运行结论。不能声称任意 NURBS 切触问题均已解决。

### 2.1 固定延伸的尺度不一致

当前 `build_all_event_trace_corrections()` 使用：

\[
\tau=\max(16\varepsilon_g,10^{-12}h),\qquad
\delta=4\tau.
\]

三例均为 `δ=1.2974806356936508e-10=64 εg`。设路径单位方向为 d̂，横截性为 α=|n·d̂|。沿路径延伸 δ 在法向上只推进约 αδ。

| 算例 | α | αδ/εg |
|---|---:|---:|
| Neumann N32 | 3.68209824e-5 | 0.00235654 |
| Dirichlet N32 | 2.86124895e-3 | 0.18311993 |
| Dirichlet N64 | 2.22955438e-3 | 0.14269148 |

局部一阶根定位误差尺度约为 εg/α；该表达式不是认证上界。N32 的这一尺度约为 5.51e-8，远大于延伸量。形式上位于线段内部，不等于数值上已经与线段端点分离。

## 3. 数学对象、精度与认证契约

### 3.1 原生几何对象

在一个 NURBS/Bézier 参数片上写成：

\[
S(u,v)=\frac{H(u,v)}{W(u,v)},\qquad H\in\mathbb R^3.
\]

要求认证区域内 W>0，曲面正则，并有与物理域一致的外法向取向。源控制点、权重、节点和参数的 IEEE 位模式作为模型的精确输入；高精度计算不被解释为恢复某个理想十进制 CAD 模型。

原生端点定义为：

\[
q=S(u_q,v_q)=H_q/W_q.
\]

`NativeSurfaceEndpoint3D{patch,u,v}` 定义几何对象，缓存 `point` 只是其代表坐标。证书必须绑定模型版本及原生参数。一个独立舍入的 double 坐标与一个 uv 元组，不自动构成精确在线的存在性证明。

### 3.2 查询语义

新接口查询由 p 与原生 q 定义的闭路径：

\[
x(t)=p+t(q-p),\quad 0\le t\le1.
\]

一般 `intersect_segment(p0,p1)` 仍表示两个给定坐标定义的线段；新接口不暗中改变旧接口语义。两种查询必须具有不同的缓存种类标识。

退化线段、无效参数、非正权区域不能继续求交。起点在边界不允许仅凭任意 bool label 当作严格内部/外部点。

### 3.3 四项独立交付条件

| 条件 | 需要证明什么 | 不能用什么替代 |
|---|---|---|
| 根与覆盖 | 每个接受根存在且唯一；全部候选区域已处理 | 小残差；“目前只找到了一个根” |
| 身份与顺序 | 同根去重正确；不同事件严格有序 | 固定距离合并；代表 t 排序 |
| 方向与状态 | entering/leaving/contact 及端点接近侧有依据 | 期望的最终侧别；parity 猜测根数 |
| 代表点精度 | 用于 jump/法向/装配的坐标满足请求精度 | 唯一性证明；仅残差收敛 |

若任一项不满足，应用层不得将路径当作 `Certified` 装配。

## 4. 原生端点的代数存在性与局部唯一性

### 4.1 复用二维齐次直线方程

定义：

\[
D=H_q-pW_q,\qquad q-p=D/W_q.
\]

选择一个已认证 Dk≠0 的主分量 k；用另外两个分量构造：

\[
G_j(u,v)=D_k\,[H_j(u,v)-p_jW(u,v)]
          -D_j\,[H_k(u,v)-p_kW(u,v)],\qquad j\ne k.
\]

因为 W、Wq 为正，G=0 等价于曲面点位于对应无限直线上。在原生端点处：

\[
G_j(u_q,v_q)=D_kD_j-D_jD_k=0.
\]

这是一条依赖原生定义的代数恒等关系，不是“某次浮点残差为零”。可复用现有 dominant-component 齐次投影与 Bernstein 导数区间框架，替换其直线定义输入；不要求重写成三维 Newton 系统。

实现必须保留共享 Hq、Wq、D 的原生表达关系及认证来源。不能把普通 double 展开得到的两个不一致常量相减，再强制赋零；`0∈G(q)` 的普通区间包含也不足以单独证明 G(q)=0。

### 4.2 闭参数盒上的端点唯一性

设 X 是包含原生 (uq,vq) 的有效闭参数盒。已有区间 Jacobian JG(X) 可用于检验：

\[
\|I-CJ_G(X)\|_\infty<1.
\]

在该盒内至多存在一个 G 的零点。与上述原生存在性见证结合，得到 `KnownEndpointUnique`。已知根可以在人工细分盒边界，不需要延伸物理线段把 t=1 变成内点。

若判据失败，只能缩盒、细分或提高精度。原因可能是区间过宽、近切、盒内含多个真根或真实奇异，不能直接归为“同一个端点”。

该证明只覆盖它所声明的参数区域。证明 X 中只有端点，不代表同 patch 的 X 外部、其他 patch 或整条路径无其他根。

## 5. 普通根的存在性、有限线段归属与精度

### 5.1 Newton 仅提供候选与预条件器

现有种子、Newton 和最近点辅助继续用于生成 x0=(u0,v0) 及近似逆 C。残差合格只形成 `Candidate`。即使 t 被 clamp 到 0 或 1 后残差很小，也不得直接标记线段内存在真根。

### 5.2 普通内点根的存在性

向外舍入计算 Krawczyk 映射：

\[
K(X)=x_0-CG(x_0)+(I-CJ_G(X))(X-x_0).
\]

在有效参数盒内满足 K(X)⊂int(X)，并满足对应存在性定理的前提；再结合 at-most-one 条件，产生 `ExistsUnique`。C 的有效性、有限区间和所有舍入条件必须由实现保证。

根落人工分割边界时，允许用相邻区域构造覆盖该根的有效隔离盒重新认证。跨 Bézier 片段必须用能覆盖全部相关分段的导数包围，不能把一个多项式片段无证外推到另一个片段。真正 patch 边界涉及拓扑 owner，应走专门处理或明确未决。

### 5.3 t 的认证区间

由上面的主分量得到：

\[
t(u,v)=\frac{W_q[H_k(u,v)-p_kW(u,v)]}{W(u,v)D_k}.
\]

在认证 uv 盒上向外舍入求值，获得 T=[tlo,thi]。要求 W、Wq 为正且 Dk 区间不含零；条件不满足时换主分量、精化或拒绝，不能不加检查地除以区间。

- T 完全在 [0,1] 外：该根不是本线段事件，但仍记录它所覆盖区域的排除依据。
- 0<tlo≤thi<1：可作为开段根。
- T 与 0 或 1 相交但身份未确定：继续精化；不能依代表点猜测所属侧。
- 原生端点身份已证明：其逻辑参数恰为 t=1；这不等于所有“靠近 1”的候选都属于端点。

### 5.4 根证书不代替代表点精度

证书保留 uv 盒、t 区间、根存在/唯一性证明及方向界。代表坐标必须按单独的精度请求精化，例如满足空间包围宽度以及 uv/t 宽度要求；一份较宽的唯一根证书不自动足够用于 jump jet 求值。

第一期保留既有几何精度目标，不通过放宽它让回归通过。去掉的是将固定 uv 半径当作根身份判据，而不是取消代表点质量要求。PDE 误差预算与几何精度关系须在后续敏感性测试中验证，不在设计阶段声称已有二阶误差证明。

## 6. 全路径覆盖与认证驱动的根关系

### 6.1 保守候选集合

BVH 查询包围盒必须包含整个原生路径。用 p 与原生 q 的区间包围构造保守线段 AABB，不能只使用舍入 q 的紧包围。模型 BVH 的节点/叶片包围、Bézier 提取与后续细分也须保持保守。

现有 double Bézier 控制网可以用作种子和加速参考；若它不是对原始 NURBS 的精确表示或认证包围，不能单独作为严格排除依据。认证层应从源数据进行保守提取/细分，或携带已证明的转换误差。

### 6.2 覆盖账本

每个候选参数盒最终处于以下一种状态：

1. `CertifiedMiss`：证明在查询段上无根。
2. `CertifiedSingleOrdinaryRoot`：盒内与查询段相关的根内容已完整确定。
3. `CertifiedKnownEndpointOnly`：盒内只含已知端点。
4. `Split`：由子盒完整覆盖，边界允许重叠但根身份须去重。
5. `Unresolved`：无法完成上述证明，整体不能交付成功。

特别禁止：在大盒 B 内找到一个小盒 X 的唯一根，就将整个 B 标成已处理。必须进一步证明 B 至多一根，或者继续完整覆盖 B\X。

不能删除端点前最后 ε 长度；也不能因为未决区域都靠近 q 就忽略。prefix 与 endpoint neighborhood 若自适应划分，二者必须无遗漏地覆盖整条物理路径。

### 6.3 三态根关系

`RootRelation3D` 取 `SameRoot / DistinctRoots / Unresolved`：

- `SameRoot`：两个存在性见证的根都位于同一有效区域，且该区域已证明至多一个根；或已经证明属于同一原生端点。
- `DistinctRoots`：认证根包围已分离，或其他严格身份依据证明不同。物理顺序仍需获得不重叠的 t 区间。
- `Unresolved`：当前信息不足，继续局部精化；区间重叠本身不是同根证明。

跨 patch 合并还需已声明拓扑及公共参数身份的证明；空间接近不是充分条件。一个物理事件只计数一次，但保留所有 incident owners 和各 smooth sheet 的几何/Cauchy 数据。

`proof_id` 标识证明对象，`event_id` 标识本次规范化路径中的物理事件；二者不能直接等同。不同路径的“第一个根”也不能共享物理身份。并行遍历顺序不应影响最终规范化顺序和事件计数。

现有 `root_edge_parameter_uncertainty()` 与 stationary witness 可用于优先级、种子和分裂建议；未经相应严格证明，不得决定认证成功或独立根数。

## 7. 事件方向、开段状态与条件端点 correction

### 7.1 光滑横截事件

使用已认证取向的外法向 n，定义 b=n·(q-p)。可以对未归一化、已取向的法向乘积做区间符号判断，避免不必要的归一化误差。

- b<0 被严格证明：进入域，continuation_sign=+1。
- b>0 被严格证明：离开域，continuation_sign=-1。
- 区间含零：增加精度/缩盒；不能按代表法向的微小正负值定方向。

端点的接近侧 m(q−) 在 b<0 时为 0，在 b>0 时为 1。此结论依赖光滑边界、正确外取向及端点隔离邻域；特征点不能套用单法向规则。

真正接触不能自动视为横截，也不能未经证明直接设 sign=0。现有多 owner 分类可复用，但普通 bool 分类回调不能仅凭函数名称就被视为严格侧别证书；证据不足须返回未决。

### 7.2 保留开段状态机

设起点状态 m0∈{0,1}，开段事件按严格顺序排列，符号为 si。继续使用：

\[
m_i=m_{i-1}+s_i,\qquad m_i\in\{0,1\}.
\]

全部开段事件处理后，增加检查：

\[
m_{\mathrm{open}}=m(q^-).
\]

该检查用于发现起点 label、事件方向或根完整性不一致。起点 label 不应被悄悄修正以使等式成立；起点在边界须明确处理。

对于所需侧 m*：

\[
s_{\mathrm{needed}}=m^*-m_{\mathrm{open}}.
\]

- sneeded=0：不加入端点 correction。
- sneeded≠0：必须与已认证端点方向一致，才加入一次端点 correction。
- 不一致：返回方向/状态错误；不能用目标侧反推或制造几何事件符号。

端点始终作为几何证书存在，并不意味着两个 restrict 分支都要添加端点 jump。现有逐事件 correction、jump jet 来源和空间模板保持不变。

| Neumann N32 baseline | 0 | 无 | 0 | +1 | 添加 q | 不添加 q |
| Dirichlet N32 Tx | 0 | 无 | 0 | +1 | 添加 q | 不添加 q |

## 8. 自适应精度、预算与复用

### 8.1 精度阶梯

第一层使用经过验证的 binary64 向外舍入区间算法。困难盒可升级到拟选的 MPFR 定向舍入后端，初始阶梯为 128 → 256 → 512 bit；这些是待实施的工作策略，不是已经验证的最佳配置。

升级必须从原始控制点/权重/节点位模式及原生端点表达重新构造认证计算，包括 Bézier 提取/细分。仅将已舍入的 Newton 结果或旧宽区间转换成更高精度，不能补回丢失的信息。

不假设 `long double` 必然更精确或具有向外舍入保证。多精度后端作为显式构建能力；未启用且 binary64 无法认证时返回 `Unresolved`，原因 `PrecisionBackendUnavailable`，不静默降级。

所有证书依赖明确的浮点执行契约：有限输入、正确的外向舍入及被审计的转换/乘加行为；认证代码不能在破坏该契约的 fast-math 优化下运行。

### 8.2 有界工作量

`PathCertificationBudget3D` 至少限制全路径累计盒数、Newton 求值次数、最近点辅助次数及精度晋级次数。重试继承累计预算，不重新清零。细分深度保留为辅助上限，不再充当唯一成本约束。

确定性计数预算为主要机制；墙钟取消只作为外部保护。耗尽预算返回 `BudgetExceeded` 和完整未决信息，不能返回已认证的部分根集。

预算的具体默认值由三条失败重放和已有正常几何查询的分布确定，并写入运行记录；本文不编造可用耗时上限或加速倍数。

### 8.3 复用边界

- 按原生端点复用：几何求值、导数、owner 候选及包含端点的叶片索引。
- 按完整路径复用：候选集合、根证书、事件排序、端点方向和覆盖账本。
- 按分支独立处理：desired_inside 与条件端点 correction。

证书依赖路径方向，不能仅按 center 跨不同 node 复用。现有 `(center,node)` 缓存可在同一不可变模型实例中继续使用；跨实例或持久化缓存须包含模型/变换版本、查询种类、坐标与参数身份及精度策略版本。

同一路径的内外侧和嵌套 Q27/Q64 cover 可共享认证结果。反向查询的几何根可通过明确的 T→[1−thi,1−tlo] 映射复用，但新接口的 known-endpoint 位于终点；反向 API 不得在没有对应端点契约时冒充同一种调用。

## 9. 回归数据与验收矩阵

### 9.1 三条固定重放输入

固定记录原生参数、当前模型与刚体变换、网格坐标，不以 CSV 中舍入的 q 作为几何定义：

| case ID | N / 姿态 | patch, u, v | 支撑点 p | 端点代表坐标，仅作核对 |
|---|---|---|---|---|
| CYL-N32-507 | 32 / baseline | 3, 0.65000000000000002, 0.25 | (0.5625,−0.28125,−0.375) | (0.5322656175648182,−0.3318957013970257,−0.305) |
| CYL-D32-17 | 32 / Tx=(0.137,0,0) | 0, 0.15000000000000002, 0.25 | (0.75,0,−0.46875) | (0.7336261359036995,0.0705503640187959,−0.305) |
| CYL-D64-29 | 64 / Tx=(0.137,0,0) | 0, 0.078947368421052627, 0.053571428571428568 | (0.75,−0.046875,−0.46875) | (0.7434195102165537,0.0126555572531406,−0.5603571428571429) |

圆柱基线为 Rout=0.55、Rin=0.25、轴心 (0.06,−0.05)、z∈[−0.63,0.67]；网格盒 [−1.5,1.5]^3，h=3/N。复现严格使用源模型及保存的参数位模式，不依赖理想有理数重新舍入是否恰好相同。

上表参数采用原采样的 round-trip 十进制。对应 IEEE binary64 位模式如下，十六进制表示数值位模式而非文件字节序：

| case ID | u bits | v bits |
|---|---|---|
| CYL-N32-507 | `0x3fe4cccccccccccd` | `0x3fd0000000000000` |
| CYL-D32-17 | `0x3fc3333333333334` | `0x3fd0000000000000` |
| CYL-D64-29 | `0x3fb435e50d79435e` | `0x3fab6db6db6db6db` |

### 9.2 必须通过的检查

| 测试族 | 验收条件 |
|---|---|
| 三条真实失败路径 | 根计数、开段顺序、端点身份、方向及两侧 correction 与第 7.3 节一致 |
| 单根多种子/细分边界 | 最终一个物理事件；根的代表点扰动不改变身份 |
| 端点前存在极近独立根 | 不因旧 tie/uv 阈值合并；未分离前不得 Certified |
| 真零点在查询段/参数盒外而边界残差很小 | 不产生段内 `ExistsUnique` |
| 局部小盒唯一但外部还有根 | 完整覆盖不能提前结束 |
| 大幅减少预算/缺少精度后端 | 明确失败原因；不返回完整成功标志 |
| 同侧双交点、三交点 | 全部物理事件保留，状态逐步合法 |
| smooth seam 多 owner | 一个物理事件、完整 owner；不能按 owner 数量跳变 |
| 真切触、重叠、端点在 feature/vertex | 符合第一期能力边界，不能强制横截或强制接触 |
| 刚体变换与路径反向 | 在对应模型精度范围内计数和身份一致；反向顺序和符号正确 |
| 所有齐次权重统一正比例缩放 | 原生几何和物理事件不变；认证运算仍保持有效包围 |
| 缓存开/关、不同遍历顺序 | 认证状态和规范化事件一致；装配结果在声明精度内一致 |
| 平面/已知多项式 restrict 再现 | Q27/Q64 现有再现性质不退化 |

现有人工端点测试使用 0.1 延伸距离，不能代替本次实际近切查询。原来的“未认证必须失败”“未知身份的重复端点必须拒绝”等测试原则继续保留；新接口通过更强证明满足契约，而不是放宽旧断言。

### 9.3 PDE 上线门槛

先完成有预算的几何重放与上述单元回归，再分别运行原配置的 N32/N64。报告内部误差、密度误差、完整/投影迹残差、GMRES 次数、setup/solve/总耗时及异常查询计数。

对相同误差定义 E32、E64，收敛阶按 log2(E32/E64) 计算。若任一求解失败、结果缺失或配置不一致，写“不可计算”，不填 0，不借用旧 Q10 或 Python 的结果。

几何认证通过并不自动证明 PDE 二阶收敛；若求解仍低阶，另行分析密度、约束和 trace 离散。本次旧运行在 GMRES 前退出，不能作为新路线的速度或收敛通过证据。

## 10. 实施次序与交付检查

1. 固定三条路径夹具、失败 dump 格式和工作量计数；不跑整套 PDE 来代替定位。
2. 引入候选/证书/覆盖账本及原生端点查询语义，完善保守几何包围。
3. 实现原生端点唯一性与普通根存在性，连同精度请求和有界重试。
4. 改为认证驱动的根关系、顺序和端点划分；同步审计 filtered 根计数及相关公共消费者。
5. 接入现有开段状态机、条件端点 correction 和路径缓存；旧入口保留作兼容/显式对照，不自动回退。
6. 几何回归、Q27/Q64 再现、原配置 PDE 验收依次完成后，才将新路线设为主力。

步骤 2–5 是配套变更，不能仅修改入口并删除失败检查就上线。完整字段、函数签名、文件拆分、诊断与测试挂载见 [代码设计文件](KFBI3D_Native_Endpoint_Code_Design_20260907.md)。

本次文档交付不修改求解代码、不引入多精度依赖、不运行 PDE，也不执行提交或推送。
